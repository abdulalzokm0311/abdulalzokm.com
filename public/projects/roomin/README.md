# Roomin assets

Drop files in this folder using the names below. Any extension is fine
(.png, .jpg, .webp). Export at 2x where you can; I measure each file and set
its exact aspect ratio, so nothing gets cropped or squashed.

Tell me once they're in and I'll wire them up.

| Filename          | What goes in it                                                      |
|-------------------|----------------------------------------------------------------------|
| `cover`           | Hero image. Also used on the home grid and /projects cards.          |
| `affinity-board`  | The FigJam affinity clustering board from synthesis.                 |
| `swot-matrix`     | SWOT prioritisation, value against implementation effort.            |
| `journey-map`     | User journey across beginning, research, searching, communication, decision. |
| `four-features`   | The four feature screens: compatibility, filters, reviews, report.   |
| `final-screens`   | Final hi-fi screens across the core flow.                            |

## Notes

**Cover.** WestJet's cover is the design composited into a desktop monitor,
which is why it reads well at card size. Roomin is a phone app, so the
equivalent is a device mockup or a tight composition of two or three screens.
A flat grid of eight screens will be unreadable in a 520x390 card.

**Crop out the slide headings.** The versions on the live site each carry a
heading like "15 · Final Design" baked in. The case study already says all of
that in real text, so export the artifact on its own.

**Resolution.** The individual phone screens on the live site are about
227x491, too small to show at any real size. Export from Figma rather than
reusing those.

**Boards.** Affinity, SWOT and journey maps are wide and dense. Export the
full board rather than a crop; the page shows them at up to 1136px and they
can be opened larger later if needed.
